# Handoff

새 세션이 바로 이어서 일할 수 있게 작업 폴더 루트에 `HANDOFF.md`를 쓴다.

순서:
1. 목표 (한두 줄)
2. 지금까지 결정: 이미 다른 문서(판단 기록 등)에 있는 내용은 반복하지 말고 경로만 적는다.
3. 끝난 것 (커밋·파일 경로로)
4. 남은 것 (우선순위 순)
5. 주의할 점 (실무자가 말한 제약, 데이터 함정)
6. 다음 세션이 처음 할 일

규칙:
- 짧게 쓴다. 이미 커밋·문서에 있는 내용은 경로만 적는다.
- 비밀번호·키·개인정보는 쓰지 않는다.
- 새 세션에는 "HANDOFF.md와 거기 적힌 문서를 먼저 읽고 시작해"라고 안내한다.
